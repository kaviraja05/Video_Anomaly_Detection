### Workflow Explanation:

1. **Video Input**: Raw surveillance video is provided as input
2. **Preprocessing**: 
   - Frames are sampled at 16 fps
   - I3D network extracts 2048-D spatio-temporal features
   - Video is divided into 32 equal segments
3. **Feature Processing**: High-dimensional features are projected to compact 128-D
4. **Temporal Modeling**: 1D convolutions capture local patterns
5. **Graph Construction**: DSM learns content-aware adjacency matrix
6. **GNN Processing**: Message passing enriches segment representations
7. **Relation Reasoning**: RA²R captures high-order dependencies
8. **Scoring**: Per-segment anomaly probabilities are produced
9. **Output**: Final prediction with temporal localization
